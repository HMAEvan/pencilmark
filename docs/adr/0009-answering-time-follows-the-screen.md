# Answering time goes to the Question on screen; within a Case, to the last sub-Question interacted with

While answering, when one Question is on screen, its time goes to that Question: opening a Question counts as interacting with it. A Case screen shows several sub-Questions at once, and opening it cannot tell them apart, so there time goes to the last sub-Question interacted with. The known, accepted error belongs to Cases only: reading the next sub-Question before interacting with it is counted towards the previous one. Case attribution is built when Cases reach the interface.

## Considered Options

- **The last object interacted with, everywhere**: rejected. On a one-Question screen it would give the time spent reading a newly opened Question to the one before it, an error that the screen already tells us how to avoid.
