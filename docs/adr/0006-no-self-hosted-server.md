# No self-hosted server through stage 2

The tool is hosted as a static site on GitHub Pages and as a claude.ai artifact. There is no backend of our own. A self-hosted server would multiply the work and could not be opened inside the Claude apps. This holds for the MVP and the first two stages (local mode, artifact mode). Stage 4, an optional self-hosted sync server on a Mac mini, may revisit it.
